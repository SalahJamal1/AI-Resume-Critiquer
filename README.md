# AI Resume Critiquer

A Streamlit app that gives AI-powered, role-tailored feedback on a resume. Upload a PDF, enter the job role you're targeting, and get structured feedback on content clarity, skills presentation, and experience descriptions — generated by a self-correcting [LangGraph](https://github.com/langchain-ai/langgraph) pipeline that grades its own output for hallucinations before returning it.

## How it works

The app is a small graph with two nodes and a feedback loop:

```
ingestion -> analyze -> (grade) -> useful?     -> END
                            |
                            +---> not useful -> analyze (retry)
```

1. **Ingestion** — the uploaded resume is loaded, split into chunks, embedded, and stored in a local [Chroma](https://www.trychroma.com/) vector store.
2. **Analyze** — an LLM reviews the resume content against the target job role and produces structured feedback.
3. **Grade** — a second LLM call checks whether the feedback is actually grounded in the resume content. If not, the graph loops back to `analyze` and retries (up to `MAX_RETRIES`, defined in `graph/consts.py`) before accepting the result.

See `graph/analyzing.png` for the rendered graph diagram.

## Tech stack

- **Streamlit** — UI
- **LangGraph** — orchestration / self-correction loop
- **LangChain** — chains and document loading
- **Ollama** — local LLM (`qwen3:1.7b`) and embeddings (`nomic-embed-text`)
- **Chroma** — local vector store for resume chunks
- **uv** — dependency management

## Prerequisites

- Python 3.13+
- [uv](https://docs.astral.sh/uv/)
- [Ollama](https://ollama.com/) running locally with the required models pulled:

  ```bash
  ollama pull qwen3:1.7b
  ollama pull nomic-embed-text
  ```

## Setup

1. Install dependencies:

   ```bash
   uv sync
   ```

2. Create a `.env` file in the project root. At minimum, nothing is required to run the app locally since it uses Ollama, but the project is wired up to support optional integrations:

   ```env
   # Optional: LangSmith tracing
   LANGSMITH_TRACING=
   LANGSMITH_ENDPOINT=
   LANGSMITH_API_KEY=
   LANGSMITH_PROJECT=

   # Optional: only needed if you swap in these providers/tools
   OPENAI_API_KEY=
   GOOGLE_API_KEY=
   TAVILY_API_KEY=
   PINECONE_API_KEY=
   PINECONE_INDEX=
   ```

3. Run the app:

   ```bash
   uv run streamlit run main.py
   ```

4. Open the URL Streamlit prints (default `http://localhost:8501`), upload a resume PDF, enter a target job role, and click **Analyze Resume**.

## Project structure

```
main.py                          Streamlit entry point
graph/
  analyze_graph.py                Builds and compiles the LangGraph workflow
  consts.py                       Shared LLM instance, node names, MAX_RETRIES
  state.py                        GraphState TypedDict shared across nodes
  ingestion.py                    PDF loading, chunking, and Chroma indexing
  nodes/
    ingestion_node.py             Ingestion graph node
    analyze_node.py                Resume analysis graph node
    grade_answer.py                Hallucination-grading conditional edge
  chains/
    analyze_chain.py               Prompt + LLM chain for resume feedback
    answer_chain.py                Prompt + LLM chain for answer-relevance grading
    hallucination_chain.py         Prompt + LLM chain for hallucination grading
```

## Notes

- The Chroma vector store persists to `graph/chroma_db/` and is reused across runs.
- `graph/ingestion.py` and `graph/nodes/analyze_node.py` can each be run standalone (`python -m graph.ingestion`, etc.) for local testing against a sample PDF.
